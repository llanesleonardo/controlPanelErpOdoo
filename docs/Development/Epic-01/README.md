# Epic-01 — Foundation and MVP shell

Scaffold and reference tasks for the control plane. **No full app build in this epic’s docs pass** — each task is implemented later against its SRD/TSD pack.

## Phases

| Phase | Focus |
|-------|--------|
| [phase-01](./phase-01/) | Foundation — taxonomy, contracts, docs/monorepo, Docker strategy |
| [phase-02](./phase-02/) | Control-plane shell — auth/users/roles, profile, theme |
| [phase-03](./phase-03/) | Ops surfaces — request console, task queue, logging, rate limits |
| [phase-04](./phase-04/) | Integrations — Odoo page, dry-run path, storage/backups |

## Rule

Every task folder contains `SRD.md`, `TSD.md`, `diagram.md`, `conops.md`.
