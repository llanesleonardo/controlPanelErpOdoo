# Structural Patterns

| Pattern | Definition |
| --- | --- |
| Adapter | Objects has the functionality you need. |
| Bridge | Separates an abstraction from its implementation. |
| Composite | Objects are organized in a tree-like structure. |
| Decorator | Adds new behavior to an object dynamically. |
| Facade | Provides a simple interface over a complex. |
| Flyweight | Reduces memory usage when a system creates a. |
| Proxy | You want objects to stand in front of another. |
