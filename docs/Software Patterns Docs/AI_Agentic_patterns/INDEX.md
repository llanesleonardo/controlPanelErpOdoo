# LLM and AI Patterns

| Pattern | Definition |
| --- | --- |
| RAG | Combines retrieval from trusted knowledge. |
| Multi-Agent Orchestration | Multi-Agent Orchestration coordinates multiple. |
| Tool Calling | Lets an LLM invoke external functions. |
| Planner-Executor | Planner-Executor separates high-level task. |
| Reflection | Makes a model critique. |
| Memory-Augmented Agent | Memory-Augmented Agent stores and retrieves. |
| Event-Driven Agents | Event-Driven Agents wake up or act in response. |
| Agent Supervisor | Monitors. |
| Human-in-the-Loop | Human-in-the-Loop inserts human review. |
| Chain-of-Thought Pipelines | Chain-of-Thought Pipelines decompose reasoning. |
| Vector Search Architecture | Stores embeddings and retrieves semantically. |
| Semantic Routing | Sends a user request to the right model. |
