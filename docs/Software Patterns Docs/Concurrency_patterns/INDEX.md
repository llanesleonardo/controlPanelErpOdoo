# Concurrency Patterns

| Pattern | Definition |
| --- | --- |
| Producer-Consumer | Producer-Consumer separates threads or tasks. |
| Thread Pool | Reuses a fixed or managed group of worker. |
| Worker Queue | Stores units of work that worker threads pull. |
| Reactor | Waits for events and dispatches them to handlers. |
| Proactor | Starts asynchronous operations and dispatches. |
| Fork-Join | Fork-Join splits a task into smaller subtasks. |
| Pipeline | Splits processing into stages where each stage. |
| Futures and Promises | Future represents a result that will be. |
| Async/Await | Async/Await writes asynchronous code in a. |
| Double Buffer | Uses two buffers. |
| Readers-Writers Lock | Readers-Writers Lock allows multiple readers at. |
| Barrier | Makes multiple threads wait until all. |
| Semaphore | Controls access to a limited number of permits. |
| Actor Model | Organizes concurrency around isolated actors. |
| Scheduler | Decides when tasks run. |
| Work Stealing | Lets idle workers take tasks from busy workers'. |
| Event Loop | Repeatedly waits for events. |
