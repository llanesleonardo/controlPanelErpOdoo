# OPS-018 — Automation fires skill on ontology action

**Owner:** SAC-007 · also SAC-004  
**Class:** External (product OPS)  
**Status:** Open  
**Actors:** System automation + optional human approver  
**Goal:** A queued/automated job triggers an **ontology action** through the same allowlisted skill path humans use — with approvals when policy requires.

## Preconditions

- Task / automation definition references a known skill or ontology action.  
- Approval policy known for write skills.

## Flow

1. Trigger creates or resumes a task.  
2. Task executes skill (dry-run first if required).  
3. If approval needed → human approve/reject ([OPS-003](./OPS-003.md)).  
4. Evidence links task id, correlation id, connector_id.

## Success

Automations cannot bypass allowlist or invent vendor RPC.

## Failure

Policy/allowlist miss → task fails visibly; no silent commit.
