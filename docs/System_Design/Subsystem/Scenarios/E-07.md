# E-07 — Operational feedback and controlled baseline update

**Owner:** Cross-cutting  
**Class:** Internal (engineering E)  
**Status:** Open  
**Actors:** Shop lead + product owner + builder  
**Goal:** Triage floor feedback (wrong ownership assumption, missing SoA, Process drift) → update ConOps/SRD/TSD when needed → verify again. Progress on a feature does not skip this loop.

## Flow

1. Capture report (e.g. “ERP isn’t our only system”).  
2. Assess ConOps/SRD impact (multi-SoA, bindings).  
3. Change baseline docs/code as allocated.  
4. Re-verify linked OPS; keep statuses Open until TR closes.

## Success

Feedback becomes controlled baseline change, not silent UI-only patch.
