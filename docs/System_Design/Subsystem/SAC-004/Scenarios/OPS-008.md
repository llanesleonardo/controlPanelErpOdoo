# OPS-008 — Run an allowlisted skill through the skills engine

**Owner:** SAC-004  
**Actors:** Operator (via control panel) or developer smoke-testing the internal engine  
**Goal:** Run a certified skill (MVP: `sales.estimate.read`) through gateway → orchestrator → connector, with evidence and correlation — never by calling Odoo from the browser.

## Flow

1. Start orchestrator with `ERP_MODE=simulate` (or `live` + Odoo env when ready).  
2. Confirm `GET /health` on the orchestrator (host-only / internal).  
3. From the UI or gateway, run execute for `sales.estimate.read` (Estimates → read).  
4. Confirm structured rows (or clear failure), `correlation_id`, and optional evidence under `STORAGE_ROOT/evidence/`.  
5. Attempt an unknown intent_code against `/skills/execute` — expect validation failure, no ERP call.  

## Success

- Only allowlisted intents run.  
- Browser never talks to orchestrator or Odoo directly.  
- Simulate works without live ERP; live uses connector settings.  
- Evidence / warnings are visible when files are written.
