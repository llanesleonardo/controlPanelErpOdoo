# OPS-009 — Pick an intent from ERP Map and open console

**Owner:** SAC-002  
**Actors:** Estimator or office lead using the control panel  
**Goal:** From the ERP Map, open a section, select an intent, and land on the Request console with the intent prefilled — without typing raw ERP codes or calling Odoo from the browser.

## Flow

1. Open `/` (ERP Map) — pick a module tile (e.g. Estimates / Sales).  
2. Land on `/sections/<slug>` — confirm intents rail lists section-scoped intents; search still works.  
3. Select an intent — review profile / call-path sketch (gateway-oriented, not free-form RPC).  
4. Use the console link (or equivalent) → `/console` with `intent_code` (and domain) in the query.  
5. Optionally Classify once to confirm taxonomy mapping via the gateway.

## Success

- Map tiles navigate to the correct section.  
- Intents are section-specific (not a single global dump).  
- Console opens with the chosen intent code available.  
- Network calls for classify go to the gateway only.
