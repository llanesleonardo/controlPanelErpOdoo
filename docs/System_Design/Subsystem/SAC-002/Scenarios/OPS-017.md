# OPS-017 — Analytics / workflow reads ontology objects

**Owner:** SAC-002 · also SAC-006  
**Class:** External (product OPS)  
**Status:** Open  
**Actors:** Analyst / estimator  
**Goal:** Dashboards or workflow screens consume **ontology object reads** (via skills), not direct vendor queries from the browser.

## Preconditions

- At least one read skill for a type used in analytics.  
- UI surface (section page, Explorer, or future analytics panel) talks only to gateway.

## Flow

1. Open an analytics or workflow view that needs shop objects.  
2. View requests gateway → skill/ontology APIs.  
3. Table/chart shows business fields; failures are honest.

## Success

No browser-held ERP/MES credentials; vocabulary stays shop-facing.

## Failure

Downstream SoA/data down → degraded messaging; no fabricated rows labeled live.
