# E-06 — Verification failure, blocked release, and recovery

**Owner:** SAC-010 · also SAC-009  
**Class:** Internal (engineering E)  
**Status:** Open  
**Actors:** V&V + release approver  
**Goal:** Failed verification **blocks** release; fix → re-verify → reconsider release.

## Flow

1. Required TP fails or evidence missing.  
2. Release blocked; defect logged.  
3. Fix in baseline; re-run verification.  
4. Only then re-enter [E-05](./E-05.md) path.

## Success

No "ship anyway" without recorded waiver against a named SHALL.
