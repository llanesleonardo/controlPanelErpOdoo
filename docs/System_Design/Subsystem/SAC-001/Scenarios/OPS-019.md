# OPS-019 — App / SDK / API via ontology (not vendor RPC)

**Owner:** SAC-001 · also SAC-004  
**Class:** External (product OPS)  
**Status:** Open  
**Actors:** Developer / integrating app  
**Goal:** External products call the **control-plane API** (intents/skills/ontology) — never raw Odoo/MES endpoints with shop credentials embedded in the client.

## Preconditions

- Gateway is the sole app entry.  
- Client authenticated; allowlist applies the same as UI.

## Flow

1. Client calls gateway skill/ontology endpoints with actor identity.  
2. Gateway enforces allowlist / rate limit.  
3. Orchestrator + connector execute.  
4. Response is domain DTO; vendor shapes stay behind ACL.

## Success

SDK/API path is ontology-governed; same safety as the control panel.

## Failure

Direct vendor URL from client is out of product contract; allowlist reject on unknown skill.
