# OPS-007 — Bring up the control-plane stack (Compose)

**Owner:** SAC-009  
**Actors:** Shop IT / developer standing up the control panel next to the ERP  
**Goal:** Get Postgres and the apps running so estimators and floor leads can use the panel — without starting the ERP inside our containers.

## Flow

1. Copy `.env.example` → `.env` and set database / gateway URLs (simulate ERP is fine for a first pass).  
2. Start Postgres: `docker compose -f docker/docker-compose.yml up -d`.  
3. Apply schema (`prisma:generate` / `prisma:push`).  
4. Start orchestrator + gateway + web (npm **or** `docker compose … --profile apps up --build`).  
5. Open the UI; hit health on gateway (and orchestrator if running on the host).  

## Success

- Postgres is healthy.  
- Gateway `/health` succeeds.  
- Web loads and can reach the gateway.  
- ERP remains external (simulate or live URL) — not a Compose service.
