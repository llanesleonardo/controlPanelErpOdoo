# E-04 — Controlled build, promotion, deployment, and rollback

**Owner:** SAC-009  
**Class:** Internal (engineering E)  
**Status:** Open  
**Actors:** Developer / ops  
**Goal:** Promote an approved control-plane baseline (Compose/host), keep deploy evidence, roll back on failure. **Edges (ERP and other SoAs) stay external.**

## Flow

1. Build images / host apps from known commit.  
2. Deploy control-plane services only.  
3. Smoke health; connectors reach external URLs.  
4. On failure, roll back; record evidence.

## Success

Deploy does not imply SoA data migration; rollback is defined.
