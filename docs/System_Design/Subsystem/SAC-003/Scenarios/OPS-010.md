# OPS-010 — Classify / resolve known intent code against taxonomy

**Owner:** SAC-003  
**Actors:** Operator or developer confirming a shop action has a known code  
**Goal:** Resolve a business action to a known `{domain}.{entity}.{verb}` code (or reject unknown codes) using the shared vocabulary package — not free-form ERP calls.

## Flow

1. Pick a shop action (e.g. “create sales order”, “adjust stock”, “post invoice”, “read estimate”).  
2. Resolve to an intent code using TaxonomyDocs / `KNOWN_INTENT_CODES` (or gateway classify when wired).  
3. Confirm `isKnownIntentCode(code)` is true for published codes.  
4. Optionally load the matching contract YAML via `loadContract(code)` for sample writes.  
5. Try an unknown string — expect rejection / false, not a silent invent.

## Success

- Sample codes from Authoring resolve as known.  
- Package taxonomy matches Authoring domains/verbs.  
- Unknown codes are not treated as executable.  
- After ContractsDocs edits, `contracts:sync` refreshes package YAML.
