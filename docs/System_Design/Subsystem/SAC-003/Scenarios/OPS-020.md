# OPS-020 — AI suggests intent; human/skill executes

**Owner:** SAC-003 · also SAC-001, SAC-004  
**Class:** External (product OPS)  
**Status:** Open  
**Actors:** Operator + AI assistant (classifier)  
**Goal:** Multimodal/open/commercial AI may **propose** a known intent; only allowlisted skills **execute**. AI cannot invent tools, models, or payloads.

## Preconditions

- Taxonomy of known intent codes.  
- Console or agent entry hits gateway classify/resolve (not free-form RPC).

## Flow

```text
  NL / multimodal input
         │
         ▼
  Classify → known intent code?
     │ yes              │ no
     ▼                  ▼
  Human confirms     Reject / ask clarify
  or policy auto
         │
         ▼
  Allowlisted skill execute
```

1. AI/helper suggests an intent from user text.  
2. System resolves only against known taxonomy.  
3. Human confirms when required; skill runs.  
4. Evidence shows suggested vs executed intent.

## Success

No new ERP/MES calls invented by the model.

## Failure

Unknown intent → stop; do not “best guess” a vendor write.
