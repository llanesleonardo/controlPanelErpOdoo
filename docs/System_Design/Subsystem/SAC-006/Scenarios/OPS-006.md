# OPS-006 — Expand related types in Vertex

**Owner:** SAC-006  
**Actors:** Lead learning process links  
**Goal:** Start from Sales Order (or Estimate) and **Search Around** along declared schema links — grow a neighborhood without spaghetti of every possible edge.

## Preconditions

- Gateway + web up; ontology catalog loaded with links between types (Estimate ↔ Contact / Quote, orders, etc.).
- No live ERP required for type-level Vertex exploration.

## Flow

1. Open **Ontology → Vertex**.  
2. Pick a **seed** type (e.g. Sales Order or Estimate).  
3. Use **Search Around** (or double-click expand) to pull in neighbor types along declared links.  
4. Confirm the neighborhood grows along schema links only — not a dump of unrelated types.  
5. Optionally save a graph template locally if the UI offers it; leave Process map as the fixed spine elsewhere (OPS-004).

## Success

- Neighbors appear according to YAML `links` on entity types.  
- Expanding stays understandable (limited hop / Search Around), not an unreadable full-mesh.  
- Process map remains the curated spine on its own tab — Vertex does not replace it.

## Failure / edge cases

| Situation | Expected |
|-----------|----------|
| Type with no links | Seed alone; empty expand is OK with a short note |
| Catalog load failure | Same clear error as Schema |
