# OPS-022 — Inspect which connector owns object properties

**Owner:** SAC-006 · also SAC-005  
**Class:** External (product OPS)  
**Status:** Open  
**Actors:** Admin / builder  
**Goal:** For an ontology type, see (or document) **which connector owns which properties** — multi-SoA ownership is explicit; ERP is not assumed to own everything.

## Preconditions

- Entity type with properties and at least one binding file (ERP and/or stub peers).  
- Schema or admin view can surface ownership summary (v1 may be docs + binding paths if UI inspector residual).

## Flow

1. Open Schema for a type (e.g. Estimate).  
2. List properties and owning connector_id / binding source.  
3. Confirm public `/ontology` responses still omit raw vendor field maps.  
4. Note split ownership cases (e.g. commercial fields on ERP SoA, later MES fields on another).

## Success

Ownership is explainable per property; architecture does not claim “ERP owns all data.”

## Failure

Ambiguous ownership → Open decision / Risk; do not silently default all properties to Odoo in requirements.
