# OPS-005 — Search estimates in Explorer

**Owner:** SAC-006  
**Actors:** Estimator  
**Goal:** List estimate objects from the live ERP when connected (or clear demo/failure messaging when not).

## Preconditions

- Gateway + web up; for live Estimate also orchestrator + Odoo (or `ODOO_MODE=simulate` / live per [OPS-001](../../SAC-005/Scenarios/OPS-001.md)).
- Ontology catalog loads (OPS-004 happy path).

## Flow

1. Open **Ontology → Explorer**.  
2. Choose entity type **Estimate**. Optionally type a search / contains string.  
3. Review the object table: columns match shop properties; note `source: live` when the ERP path succeeds.  
4. Open a row’s property layout if offered.  
5. Optionally pick another type (e.g. Inventory): expect **demo** rows with a clear note when no live read skill is allowlisted — not fake “live” claims.

## Success

- Estimate shows `source: live` when ERP/simulate skill path works, **or** a clear failure message (not a silent empty success).  
- Demo types are labeled as demo.  
- No vendor model names (`customer.estimate`) in the Explorer chrome.

## Failure / edge cases

| Situation | Expected |
|-----------|----------|
| Skill not allowlisted | Demo objects + note that live skill is unavailable |
| Odoo down in live mode | Failure messaging; operator may switch to simulate ([OPS-001](../../SAC-005/Scenarios/OPS-001.md)) |
