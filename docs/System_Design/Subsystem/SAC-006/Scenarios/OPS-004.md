# OPS-004 — Browse the business map (Schema)

**Owner:** SAC-006  
**Actors:** Anyone learning the shop model (estimator, floor lead, new hire)  
**Goal:** Find Estimate, Inventory, Manufacturing, Quality, Shipping, and related types — see properties, links, and certified actions — without editing YAML in the browser.

## Preconditions

- Gateway + web up (Postgres as needed). Ontology package loaded into the gateway image or workspace.
- No ERP connection required for Schema / Process map browsing.

## Flow

1. Open **Ontology** (`/ontology`). Land on **Schema** (default).  
2. Search or select a type (start with **Estimate**).  
3. In the inspector, read **properties**, **links**, and **actions** (skill codes such as `sales.estimate.read`). Confirm no Odoo model names appear.  
4. Switch to **Process map**. Confirm the curated commercial → make → ship spine (not every link). Click a node to see its actions in the panel.  
5. Optionally open the “How to add…” help and confirm it points at `resources/packages/ontology/` — not an in-page editor.

## Success

- Catalog loads with multiple shop types (not an empty page).  
- Estimate (and peers) show properties / links / actions in business language.  
- Process map shows the curated spine; Schema remains searchable.  
- No browser edit of YAML required; ERP Map still available for running intents.

## Failure / edge cases

| Situation | Expected |
|-----------|----------|
| Gateway missing ontology package | Clear load error — not a blank silent UI |
| Single type only | Still inspectable; help text still points at package path |
