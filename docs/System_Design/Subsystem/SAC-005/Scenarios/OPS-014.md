# OPS-014 — Enable / health-check a non-ERP SoA connector

**Owner:** SAC-005  
**Class:** External (product OPS)  
**Status:** Open  
**Actors:** Admin / IT  
**Goal:** Treat a second (or Nth) **system of action** as a first-party catalog peer — configure, test health, enable skills — same path as ERP, not a special case.

## Preconditions

- Product has (or stubs) a second SoA connector id in the catalog (e.g. MES / SCM placeholder or future real adapter).  
- Admin role can edit connector config.

## Flow

1. Open Integrations / connector catalog.  
2. Select a **non-ERP** SoA connector.  
3. Enter URL / credentials (masked on read).  
4. Run **Test connection** → `ok` | `degraded` | `down`.  
5. Enable only skills that connector declares.

## Success

Health and enablement work without implying ERP is required for the catalog itself. ERP remains available as another peer.

## Failure

Bad credentials → honest down/degraded; secrets never logged in plaintext.
